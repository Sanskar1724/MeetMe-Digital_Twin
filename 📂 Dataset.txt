📂 Dataset

The MeetMe Dataset is a manually curated conversational dataset created from my personal journals, notes, conversations, reflections, and learning experiences. Its purpose is to fine-tune a language model to better reflect my communication style, reasoning process, and decision-making patterns rather than teach new factual knowledge.

Unlike datasets collected from public sources or generated by AI, every training sample was written or reviewed manually to preserve authenticity and consistency.

Dataset Statistics
Total Samples: 171
Format: ChatML (messages)
Language: English
Task: Supervised Fine-Tuning (SFT)
Purpose: Personality adaptation and conversational fine-tuning
Data Sources

The dataset was curated from:

📖 Personal journals
📝 Learning notes
💬 Personal conversations
💡 Reflections and opinions
🎯 Career and project discussions
🧠 Problem-solving and decision-making experiences
Dataset Structure

Each sample follows the ChatML conversational format:

{
  "messages": [
    {
      "role": "user",
      "content": "How do you approach learning a new technology?"
    },
    {
      "role": "assistant",
      "content": "I usually break complex topics into smaller systems, understand how each part connects, and then learn by building projects instead of only watching tutorials."
    }
  ]
}

Data Preparation

Each conversation was manually processed through the following pipeline:

Raw text collection
Session extraction
Data cleaning
Grammar refinement (while preserving original meaning)
Instruction–response pairing
ChatML conversion
Manual quality review
Limitations
Small-scale dataset (171 samples)
Focused on one individual's communication style
Not intended as a general conversational dataset
Reflects personal opinions and experiences rather than objective facts
